# Project workflow

После завершения запрошенных пользователем изменений в этом проекте:
1. Проверяй изменения и выполняй подходящие проверки.
2. Сохраняй завершённые изменения коммитом Git.
3. Отправляй коммит в origin/main (https://github.com/ivanlakiz1993-cpu/NRG).
4. Если отправка не удалась, сообщай пользователю; не утверждай, что GitHub обновлён.

Не отправляй секреты, .env, зависимости и новые временные файлы. Не используй force push.
