# NRG: интерактивная сцена

Готовый к размещению статический сайт находится в папке `site/`.

## Передача и размещение

Передайте клиенту папку `site` или загрузите **содержимое** этой папки в корневой каталог сайта на хостинге. Главная страница — `index.html`; стили и сценарий подключаются по относительным путям из `assets/`. Сборка, серверная часть и внешние библиотеки не требуются.

Для локального просмотра можно открыть `site/index.html`. На хостинге используйте HTTPS. Главная сцена прокручивается вместе со страницей; её размеры и разрешение холста подстраиваются под окно браузера и мобильные устройства.

## Браузеры

Сайт рассчитан на актуальные версии Chrome, Edge, Firefox и Safari, включая мобильные браузеры. Для сцены нужны JavaScript, Canvas 2D и `Path2D`. Если браузер не поддерживает эти возможности, сайт показывает сообщение о требованиях. Высота экрана имеет резервное значение для браузеров без `svh`; параметр «уменьшить движение» отключает непрерывное обновление анимации.

Папки с черновиками, историческими снимками и проверкой остаются вне `site/` и не нужны для публикации.
