# NRG: интерактивная сцена

Папка `site/` — самодостаточная версия сайта для передачи клиенту. Чтобы развернуть её на обычном хостинге, загрузите **содержимое** папки `site/` в корень сайта. Главная страница пакета — `index.html`; CSS и JavaScript подключены относительными путями. Сборка, серверная часть и внешние библиотеки не требуются.

GitHub Pages проекта публикует корень репозитория. Корневой `index.html` открывает ту же сцену, используя файлы из `site/assets/`; для клиентского хостинга используйте готовую самодостаточную папку `site/`.

Сцена подстраивается под размер окна и мобильные устройства. Она рассчитана на актуальные Chrome, Edge, Firefox и Safari. Для локальной проверки откройте `site/index.html`.

Папки с черновиками, историческими снимками и проверками остаются вне пакета `site/`.
